// neural networks from first principles

mentats

A neural network library written from scratch in Rust. Tensors, GEMM-based convolutions, autoencoders and class-conditioned generative models, with one external dependency.

View on GitHub crates.io docs.rs

01 What is mentats

From scratch

Every operation (matmul, convolution, pooling, upsampling, backprop, Adam) is written by hand on flat Vec<f32> tensors. No BLAS, no autograd framework. rand is used only for weight init.

Fast

Cache-friendly i-k-j matmul with auto-vectorised fast paths, im2col/col2im convolutions, 4D mini-batches, and fat-LTO release builds.

Generative

Classifiers, VAEs and conditional VAEs with free-bits KL and β-annealing, all assembled with a fluent Network::builder() API.

let mut encoder = Network::builder()
    .reshape(vec![1, 28, 28])
    .conv2d_kaiming(1, 16, (3, 3))
    .relu()
    .max_pool2d()
    .conv2d_kaiming(16, 32, (3, 3))
    .relu()
    .max_pool2d()
    .flatten()
    .build();
